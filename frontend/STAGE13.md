## Перенесено 1:1 (кратко; подробности — в докстринге каждого файла)

- **Живая карта** — folium/geopandas HTML встроен через `<iframe>` поверх готового файла, а не перерисован на Leaflet заново.
- **Таксация** — карточка-досье (площадь/категория/возраст/формула состава/таблица по породам), скрыта до первого поиска.
- **Лесокультуры** — участки + журнал мероприятий; типы "Перевод"/"Списание" автоматически меняют статус участка (как в `screen.py:_save`).
- **Расход/ЕГАИС** — баланс лимит/факт/остаток по породам и сортиментам (KR/SR/ML/DROVA/HVOROST), наряды-задания с позициями, импорт ЕГАИС и экспорт книги расхода — фоновые задачи.
- **Инспекция** — сроки, чек-лист (стандартный + свои пункты), пресеты, Справка и полная форма Акта освидетельствования (~35 полей).
- **Архив** — ручная загрузка (без ИИ-распознавания — в desktop это тоже было убрано ещё до переноса), поиск по названию/тегам/типу через SQL.
- **Календарь** — 6 типов периодичности, "текущий срок" считается на лету (`compute_status`), а не хранится записями на каждую дату.
- **ИИ-журнал** — разбор входящих отчётов telegram-бота, перенос в `completed_works` с подстановкой должности по ФИО, фильтруемый журнал выполненных работ.

## Сознательно упрощено / не перенесено

- **Раскрой Раздел "Осветление"** (`screens/raskhod/osvetlenie/`) — отдельный поддомен с ИИ-распознаванием проб, не входит ни в один из перенесённых экранов.
- **"Создать наряд рубок ухода"** из ИИ-журнала — кросс-экранная связь с экраном "Рубки ухода", которого нет в Sidebar веб-версии вообще.
- **Создание/удаление пресетов** (комиссия делянки/акта освидетельствования) — только применение готового пресета, не сама форма управления пресетами.
- **Слой "Усыхание леса" поверх карты** (Живая карта) — вынесен в отдельную таблицу под картой вместо инъекции JS в чужой `<iframe>`.
- **Drag-and-drop** файлов (МДО/архив) — везде заменён обычным `<input type="file">`.
