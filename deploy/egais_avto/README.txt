РОБОТ ВЕЧЕРНЕЙ ВЫГРУЗКИ ЕГАИС → ЛЕСОВОД
=======================================

Что делает каждый вечер (сам, без тебя):
  1. Запускает ЕГАИС с ярлыка на рабочем столе и входит по паролю
     (если ЕГАИС уже открыт — берёт открытое окно).
  2. Открывает «Склад → Реестр движения по складам».
  3. Ставит период с 01.01 текущего года по сегодня
     (в январе — с 01.01 прошлого года, пока его ещё правят).
  4. Проверяет галочки «Тип документа»: Перевод в сортимент, Расход при
     реализации потребителю, Приход, Расход при внутреннем перемещении.
  5. Жмёт «Получить» (F7), ждёт, жмёт «Сформировать Excel», забирает файл.
  6. Проверяет файл и заливает в Лесовод (тот же импорт, что кнопка на
     сайте; повторная заливка ничего не задваивает).
  7. Пишет итог в posledniy_rezultat.txt и подробный лог в папку logi.

УСТАНОВКА (один раз, на ПК, где стоит ЕГАИС)
  0. Если нет Python — поставить Python 3.11+ с python.org,
     галочка «Add python.exe to PATH».
  1. Распаковать эту папку куда угодно, например C:\lesovod_egais\
  2. Запустить ustanovit.bat. Он:
       - поставит библиотеки,
       - откроет nastroyki.ini — вписать логин ЕГАИС, адрес и логин Лесовода,
       - спросит пароли и спрячет их в «Диспетчер учётных данных» Windows
         (в файлах паролей нет),
       - создаст задачу в Планировщике (по умолчанию 20:00).
  3. Пробный прогон: zapustit_seychas.bat — смотреть, руками ничего не трогать.
     Можно сначала без заливки: zapustit_seychas.bat --bez-zagruzki

ВАЖНО ПРО ЭКРАН
  Робот нажимает кнопки по-настоящему, поэтому в 20:00 Windows должна быть
  залогинена и НЕ заблокирована:
    - Параметры → Учётные записи → Варианты входа → «Требовать вход»: Никогда;
    - Заставка: снять «Начинать с экрана входа в систему»;
    - Электропитание: «Переводить в спящий режим»: Никогда (экран гаснуть может).
  Если заходишь на этот ПК по RDP — после отключения RDP сеанс блокируется,
  поэтому заходи лучше через AnyDesk, он сеанс не блокирует.

ЕСЛИ ЧТО-ТО НЕ ТАК
  - Открыть posledniy_rezultat.txt и logi\<год-месяц>.log, там написано,
    на каком шаге споткнулся; рядом лежит скриншот момента ошибки.
  - Если робот не находит пункт меню/поля — открыть ЕГАИС на вкладке
    «Реестр движения по складам», запустить razvedka.bat и прислать
    razvedka.txt + картинку из logi — подстроим под твою версию ЕГАИС.
  - Сменился пароль — nastroit.bat.
  - Поменять время — Планировщик заданий → папка Lesovod → «Vygruzka EGAIS».
